# הפלייליסטים של לירם 🎧

אתר בסגנון אייפוד-ננו לבר מצווה של לירם. בוחרים פלייליסט, מסובבים את הגלגל או נוגעים בשיר, והשיר מתנגן באפליקציית ספוטיפיי שפתוחה באייפד.

- כתובת: https://roee3372-afk.github.io/liram-bar-mitzvah/
- נדרש: חשבון Spotify Premium, ואפליקציית ספוטיפיי פתוחה באותו מכשיר.
- רשימות השירים נטענות ישירות מהפלייליסטים בחשבון, כך ששינוי בספוטיפיי מופיע באתר.
